# الطب النبوي — ابن قيم الجوزية

قارئ ويب كامل لكتاب **الطب النبوي** لابن قيم الجوزية (محمد بن أبي بكر بن أيوب، شمس الدين، ت 751هـ)، منشور دار الهلال / بيروت.

## الميزات
- قراءة كاملة على **131 فصلاً** بنصّ مشكول نظيف.
- بحث فوري في كل الفصول مع تظليل النتائج والتنقّل بينها.
- قائمة جانبية للفصول + تنقّل بالكيبورد (↑ ↓ Enter Esc).
- تكبير/تصغير الخط، الوضع الليلي، تصميم متجاوب (جوال/حاسوب).
- يعمل **أوفلاين** عبر Service Worker (PWA).

## البنية
```
index.html            الواجهة
script.js             المحرّك (تحميل، بحث، تظليل، تنقّل)
sw.js                 Service Worker (tibb-nabawi-v1)
site.webmanifest      بيانات PWA
icon.svg              الأيقونة
manifest.json         فهرس الفصول [{id,title,file}]
chapters/ch-001.json  محتوى كل فصل {id,title,content}
build_tibb.py         أداة توليد الفصول من نصّ الشاملة
```
